PRIYA & SUBHASH — INTERACTIVE WEDDING INVITATION

FILES
- index.html: main webpage
- styles.css: visual design and responsive layout
- script.js: opening, calendar downloads, RSVP and sharing
- page-1.jpg, page-2.jpg, page-3.jpg: original invitation pages
- music.mp3: optional background music file (not included)

PREVIEW
Open index.html in a modern browser. For best testing, use a local web server.

PUBLISH
Upload all files in this folder to the same directory on your web host (for example, the public folder of your existing website).

OPTIONAL MUSIC
Add a music file named exactly music.mp3 to this folder. The music starts when the visitor clicks Open invitation. The music button remains available to pause/resume it. Default volume is 16% and can be changed in script.js. Use audio you have permission to publish.

RSVP NOTE
The RSVP form prepares a WhatsApp message and opens WhatsApp's share flow. It does not store responses or send them to a database. To send RSVPs to a particular host number, replace the wa.me/?text= link in script.js with wa.me/COUNTRYCODEPHONENUMBER?text= after adding the host's permission and number.
